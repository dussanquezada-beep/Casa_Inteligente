04 · TECNOLOGÍAS

La tecnología detrás del proyecto.

La propuesta combina Arduino, sensores, actuadores y programación para representar una vivienda automatizada.

🧠

Arduino / PLUS Board

La placa funciona como controlador y ejecuta las instrucciones programadas.

👁️

Sensores

Detectan condiciones del entorno como luz, movimiento o temperatura.

⚙️

Actuadores

LED, motores y servomotores realizan las acciones indicadas.

💻

Programación

El código define las condiciones y respuestas del sistema.

🌐

Control

El concepto puede incorporar control remoto según la implementación.

🔌

Electrónica

Las conexiones entre placa, sensores y actuadores permiten construir el prototipo.
