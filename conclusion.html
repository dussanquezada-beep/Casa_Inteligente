05 · CONCLUSIÓN

Una vivienda inteligente es más que tecnología.

Es una herramienta que puede utilizarse para resolver problemas reales y mejorar la vida cotidiana.

Conclusión del proyecto

Este proyecto demuestra cómo la programación y la electrónica pueden combinarse para crear soluciones de automatización. Una casa inteligente puede controlar luces, cortinas, accesos y otros elementos mediante sensores y dispositivos programables.


Uno de los puntos más importantes es la accesibilidad. Para una persona que no puede levantarse fácilmente, caminar hasta un interruptor o realizar ciertas tareas, la automatización puede significar mayor comodidad e independencia.


Como proyecto técnico-profesional, esta casa inteligente permite aplicar programación, electrónica, sensores, actuadores y diseño web en una solución orientada a una necesidad real.
